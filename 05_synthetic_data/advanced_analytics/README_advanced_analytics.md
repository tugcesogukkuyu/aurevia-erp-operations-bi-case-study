# Advanced Analytics Extension

## Project

**Aurevia ERP Operations & BI Dashboard**

## Purpose

This folder contains the Python-based advanced analytics extension added to the Aurevia ERP Operations & BI Dashboard project.

The extension supports two additional Power BI pages:

| Page | Purpose |
|---|---|
| 07 - Sales Operations Command Center | Refreshable management reporting screen for sales, profitability, receivables, and operational alerts |
| 08 - Customer Portfolio Action Model | Python K-Means based customer segmentation model for sales growth and collection-risk decisions |

---

## Business Problem

The original dashboard provided operational reporting across sales, product profitability, inventory, receivables, and supplier performance.

The advanced analytics extension addresses a more specific management problem:

```text
Management needs to identify which customer groups can support revenue growth
without increasing collection risk and profitability risk.
```

The solution combines a SQL reporting layer, Python-based feature engineering, K-Means customer segmentation, and Power BI decision reporting.

```text
SQL Server reporting views
        ↓
Python feature engineering
        ↓
K-Means customer segmentation
        ↓
Customer segment output tables
        ↓
Power BI decision screen
        ↓
Sales and collection action outputs
```

## Customer Segmentation Model

### Model Type

```text
Python K-Means Clustering
```

### Business Objective

The model is designed to answer the following business question:

```text
Which customer groups can support revenue growth without increasing collection
risk and profitability risk?
```

The output is used to classify customers into business-readable segments and support sales, collection, and portfolio management decisions.

---

## Feature Set

The model uses customer-level commercial, profitability, collection, and behavioral indicators.

| Feature | Business Meaning |
|---|---|
| `TotalRevenue` | Customer revenue contribution |
| `GrossMarginPercent` | Profitability quality |
| `AvgMonthlyOrderFrequency` | Order regularity |
| `CollectionRate` | Payment / collection quality |
| `OpenBalanceRatio` | Receivables exposure relative to revenue |
| `ProductCategoryDiversity` | Product basket diversity |

---

## Cluster Labels

The model creates four business-readable customer groups.

| Cluster | Business Meaning | Recommended Action |
|---|---|---|
| Strategic Value Customers | High revenue, strong margin, good collection quality | Protect / Retain / Upsell |
| Growth Potential Customers | Healthy commercial profile with room for expansion | Grow / Cross-sell |
| Collection Risk Customers | Revenue exists but open balance and collection risk are high | Collect First / Monitor Credit |
| Low Contribution Customers | Low contribution and lower strategic priority | Low-Touch Service |

---

## Python Model Flow

```text
Load customer feature dataset
        ↓
Validate required columns
        ↓
Clean and prepare numeric features
        ↓
Scale features with StandardScaler
        ↓
Run K-Means clustering with K=4
        ↓
Convert numeric clusters into business labels
        ↓
Calculate customer priority score
        ↓
Generate CSV outputs
        ↓
Optionally write results back to SQL Server
```

## Execution - SQL Mode

Set environment variables:

```bash
export AUREVIA_SQL_SERVER="localhost,1434"
export AUREVIA_SQL_DATABASE="AureviaERPBI"
export AUREVIA_SQL_USERNAME="sa"
export AUREVIA_SQL_PASSWORD="AureviaERP2026!"
export AUREVIA_INPUT_MODE="sql"
export AUREVIA_WRITE_TO_SQL="true"
```

Run customer segmentation:

```bash
python customer_segmentation_kmeans.py
```

Run sales reporting automation:

```bash
python sales_reporting_automation.py
```

---

## Execution - CSV Mode

CSV mode can be used when SQL Server is not available.

Expected input file:

```text
customer_segmentation_input.csv
```

Set environment variables:

```bash
export AUREVIA_INPUT_MODE="csv"
export AUREVIA_INPUT_CSV="customer_segmentation_input.csv"
export AUREVIA_WRITE_TO_SQL="false"
```

Run:

```bash
python customer_segmentation_kmeans.py
```

## Notes

The management Power BI page does not display technical metrics such as Silhouette Score by default.

Silhouette Score is retained in the technical model output and documentation because it is useful for model validation, but it is not a management-facing KPI.

This keeps the dashboard focused on business action rather than academic machine learning diagnostics.
