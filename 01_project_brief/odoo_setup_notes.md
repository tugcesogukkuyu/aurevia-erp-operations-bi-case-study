# Odoo ERP Setup Notes  
## Aurevia ERP Operations & BI Dashboard Case Study

### 1. ERP Portal

The ERP operational layer of this project is implemented using Odoo ERP.

Odoo is used to demonstrate hands-on ERP portal usage across customer management, supplier management, product setup, purchasing, inventory, sales, invoicing, and payment tracking workflows.

---

### 2. Company / Database Name

Company Name:

Aurevia Professional Supply

---

### 3. Installed ERP Applications

The following Odoo applications are used in this project:

| Application | Purpose |
|---|---|
| Contacts | Customer and supplier master data |
| CRM | Lead and opportunity tracking |
| Sales | Quotation and sales order management |
| Purchase | Supplier purchase order management |
| Inventory | Stock receipt, delivery, and warehouse movement tracking |
| Invoicing / Accounting | Customer invoicing and payment tracking |
| Reporting | Operational ERP reports and exports |

---

### 4. ERP Usage Scope

The ERP portal will be used to create a representative operational flow:

1. Create customer records
2. Create supplier records
3. Create product and service records
4. Create purchase orders
5. Receive products into stock
6. Create sales orders
7. Process delivery and stock-out
8. Create customer invoices
9. Track payment status
10. Capture ERP screen outputs for documentation

---

### 5. Portfolio Positioning

This ERP setup is not positioned as corporate ERP employment experience.

It is positioned as a hands-on ERP case study where core ERP modules and workflows are implemented in a realistic business scenario.

The purpose is to demonstrate ERP navigation, operational process understanding, transaction flow awareness, UAT readiness, and ERP-to-BI reporting capability.
